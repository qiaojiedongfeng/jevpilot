# 在真实游戏仿真中训练障碍驾驶

这是独立的第二阶段实验。环境复用 `Simulation`、挑战编辑器的 `applyChallengeActors`、原游戏碰撞检测与道路占用；浏览器使用原 `DriveScene` 3D 渲染器，策略直接输出转向和踏板。页面实际执行策略和物理，不是预录回放，也没有内置规则绕行控制器。

## 启动 3D 实验页

```powershell
npm run dev
```

打开 `http://localhost:5173/challenge-lab.html`。如果开发服务使用其他端口，保持同一路径。

1. 默认是原游戏试车场，有一辆挡路的静止汽车。可切换左右车道、修改障碍纵向位置、调整起终点路线米数和时限。
2. 可以导入原挑战编辑器导出的 version=2 JSON，支持其车辆、行人和路径。背景交通默认关闭，已有挑战对象按原逻辑行动，地图建筑仍参与碰撞。
3. 点击“导出当前挑战供训练”，保存到本地。
4. 选择新检查点里的 `policy.json`，通过固定推理样例校验后，点击“开始驾驶”。可暂停、重置并切换跟车/俯视/车内视角。

目前起终点以**地图原导航路线上的米数**指定，相距至少 15 米，并与挑战对象保持至少 7 米距离；不是任意路网上自由点击选点。成功要求距终点小于 3 米且速度低于 1 m/s。道路外车身比例超过 10% 持续 0.1 秒判失败；碰撞或任务超时立即结束。页面慢时仿真放慢，不跳过物理子步。

## 训练

```powershell
conda activate jevpilot-rl
python training/challenge_train.py --steps 200000 --run-dir artifacts/rl/challenge-my-run
```

默认训练集是在同一试车场内改变障碍所在车道及纵向位置，并给初始位置/朝向小幅扰动。部分场景障碍在对向车道，不必绕行；固定验证使用留出种子 2000000000～2000000009，不代表未见城市或复杂交通的泛化能力。

针对编辑器导出的布局训练：

```powershell
python training/challenge_train.py --challenge path/to/rl-challenge.json --steps 200000 --run-dir artifacts/rl/custom-challenge
```

自定义文件可增加 `"task": {"startS": 0, "goalS": 60}`；3D 实验页导出时会自动写入。没有 task 时使用地图原始起终点。**固定自定义场景不会自动随机改动障碍，因此固定布局上的高分不能视为泛化成绩。** 当前没有自动课程晋级。

`--hours 8` 设置最多 8 小时，`--steps` 是本次追加步数上限，取先到者；完整更新之间检查预算。运行目录放置空文件 `STOP` 可以正常停止，Ctrl+C 只保证此前完整检查点可用。恢复命令：

```powershell
python training/challenge_train.py --resume artifacts/rl/challenge-my-run/step-0000200704 --steps 100000 --run-dir artifacts/rl/challenge-resume
```

检查点名以实际 `latest.json` 为准；恢复要求观测规范和源码哈希相同。保留模型/优化器/步数，从新回合继续；当前不恢复完整随机状态和环境，不承诺逐步精确恢复。尚未进行长时运行可靠性验收。

## 模型与感知边界

- 96 维结构化观测：自车、终点、前方路线及最多 8 个附近交通对象/建筑。含对象尺寸、朝向和速度；页面显示被容量限制排除的对象数。
- 感知来自模拟器坐标，包括遮挡后的对象，**不是相机视觉或真实传感器**。缺失对象有有效位，观测统一固定尺度裁剪。
- 模型使用 PPO MLP。`policy.zip` 用于 Python 续训；`policy.json` 只包含确定性 actor 权重，浏览器逐层计算 tanh 和输出裁剪，不加载任意可执行 Python 对象。
- 导出文件附带 Python 动作样例，浏览器加载时误差超过 1e-5 拒绝运行。模型性能仍取决于训练，接口校验通过不代表会避障。
- 已保存的直路模型属于 `straight-pass-v1`，不能加载到这个页面。旧直路检查点的严格源码校验绑定此前版本；需要用已推送的 `dd4da23` 源码恢复，而不是跳过兼容检查。旧二维回放 HTML 仍可直接观看。

## 首轮实测：尚未学会

运行 `artifacts/rl/challenge-second`，随机种子 42，训练 153600 步，最后更新累计计时约 145 秒（最终考试另计）。10 个固定验证场景：

| 步数 | 成功 | 碰撞 | 离路 | 超时 | 平均距终点 |
| --- | --- | --- | --- | --- | --- |
| 51200 | 0% | 0% | 0% | 100% | 57.45 m |
| 102400 | 0% | 0% | 0% | 100% | 56.72 m |
| 153600 | 0% | 0% | 0% | 100% | 56.77 m |

模型主要表现为低速或原地等待，**不能宣称已经会绕障**。从直路通过直接升级为“绕障并停车”尚未产生足够成功经验；低事故率在这里是没有完成任务的保守行为。下一实验应在同一 96 维接口内加入短距离到达/停车场景和逐步增加障碍的采样课程，并对照进度奖励与等待成本；不是直接放大训练时长。

工程验证：10 项 JS 训练环境测试、3 项 Python 测试通过，生产构建通过；浏览器实测原 3D 场景、Python/JS 推理对照、驾驶/暂停、障碍重置通过。没有重跑此前已知有 11 项失败的全项目测试，也不宣称这些历史失败已修复。
