# 障碍挑战训练与 3D 驾驶

目标：从空直路验证推进到真实游戏任务。复用 Simulation、challenge-model 的车辆/行人、道路占用与碰撞检测，由策略直接控制踏板。在原 DriveScene 中实际执行策略，而不是只展示轨迹。

本轮交付：
1. 独立 challenge-v1 观测与奖励接口，支持挑战编辑器 version=2 导出文件及可配置起终点（沿原导航路线的位置）。默认空背景交通；挑战车辆按原逻辑移动。
2. 固定长度自车、前方路线、近邻障碍观测，结构化信息来源明确，不称为视觉感知。
3. PPO CPU 训练/固定留出障碍位置评估，导出确定性 MLP 权重；浏览器对照固定样例校验推理误差。
4. 3D 实验页复用原游戏渲染器：设置默认试车场起终点和障碍位置、导入挑战、加载策略、开始/暂停/重置。使用固定时间步，与训练同一环境代码。
5. 记录成功率/碰撞率/离路率与限制。训练效果不足则报告，不使用规则绕行冒充模型能力。

先验证单辆静止障碍，移动障碍与完整城市泛化仍需后续训练。旧直路检查点使用已推送的 dd4da23 源码恢复；新模型使用不同观测规范，禁止混用。
