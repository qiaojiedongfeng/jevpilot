# 自动课程训练实施计划

**目标：** 在现有 96 维观测、PPO、控制与奖励下，逐步训练停车、避障和布局泛化。

**架构：** JS 按种子生成四级场景；Python 在回合边界采样课程，以独立固定阶段验证决定升级。独立固定完整挑战用于 best 选择，保存课程状态、评估历史和离线曲线。

**技术：** 现有 Node 仿真、Gymnasium、Stable-Baselines3、离线 HTML/SVG。

1. 在 challenge-environment.js 添加无障碍短途、偏置障碍、挡路障碍和变化布局生成器；测试确定性、起终点安全距离与接口一致性。
2. 添加 curriculum.py：课程采样、连续两次达标升级、25% 复习、固定阶段/完整验证集、评估历史曲线。测试采样和晋级逻辑。
3. challenge_train.py 默认启用课程；--challenge 或 --no-curriculum 保留固定任务训练。定期考试，保存课程状态，最终保存也更新 best；连续无改善给出提示。
4. 用 Python/Node 测试、构建、短训练与恢复测试验证。更新 CHALLENGE.md，说明指标、运行命令、源码兼容限制和验证边界。

用户已授权按四阶段方案直接实施。保留当前未提交成果，不创建丢失这些成果的新 checkout。此次不改变奖励，也不以短烟雾测试宣称训练已收敛。
